# Isla Louise Blog

Personal blog by Isla Birnie — travel adventures and book reviews from life aboard a sailboat.

[www.islalouise.com](https://www.islalouise.com)

## Setup

Built with [Jekyll](https://jekyllrb.com/) and deployed to GitHub Pages via GitHub Actions.

```
bundle install
bundle exec jekyll serve
```
